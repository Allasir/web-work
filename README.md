## 🎓 University Web Project Description: <br>
This project was developed as a final university assignment demonstrating proficiency in modern web development 
techniques and server-side programming.
The primary goal was to create a secure, dynamic web application with user authentication and transactional email capabilities.

## 🛠️ Technologies Used: <br>
The application utilizes a standard LAMP/XAMPP stack foundation, emphasizing backend stability and data integrity.

Backend & Logic: PHP was used for all server-side logic, session management, and processing user requests (sign-up, sign-in, profile retrieval).

Frontend & Interactivity: JavaScript (JS) was implemented to enhance user experience (UX) through client-side validation and dynamic interface elements, such as the responsive Hamburger Menu functionality.

Database: A SQL database (e.g., MySQL) was employed to store and manage structured data, including user credentials, verification tokens, and profile information.

Security & Authentication: The project features a robust Email Verification system upon registration to ensure user authenticity and prevent unauthorized access.
